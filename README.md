# Práctica de Laboratorio 1: Análisis Descriptivo del Tráfico en Madrid
**Asignatura:** Estadística  
**Grado:** Ingeniería de Computadores - Universidad de Alcalá (UAH)  
**Curso:** 2026/2027  
## 1. Introducción
El objetivo de este proyecto es realizar un análisis estadístico descriptivo comparativo de la variable cuantitativa *Hora del accidente* entre los distritos **Centro** y **Puente de Vallecas**, utilizando los datos oficiales del Ayuntamiento de Madrid.

## 2. Metodología y Puntos Voluntarios (Nota Máxima)
* **Entorno y Lenguaje:** R y RStudio.
* **Soporte de Inteligencia Artificial:** Se han utilizado herramientas de IA Generativa para la estructuración del código en R y la optimización de funciones.
* **Visualización Avanzada:** Se ha incluido un gráfico interactivo HTML generado con la librería `plotly`.
* **Publicación en GitHub:** Informe totalmente redactado y publicado en formato Markdown.

## 3. Resultados Estadísticos Descriptivos

## 4. Conclusiones
La siniestralidad vial en ambos distritos presenta un comportamiento horario prácticamente simétrico y concentrado: el 50% central de los accidentes ocurre entre las 10:00 y las 19:00 horas, coincidiendo con la franja de mayor flujo laboral y comercial de la capital.
